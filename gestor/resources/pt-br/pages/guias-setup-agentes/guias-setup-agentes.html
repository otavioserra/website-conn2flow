Guias de Setup dos Agentes (Antigravity 2.0, Claude Code, Codex e Cursor)

Disponível Antigravity 2.0 · Claude Code · Codex · Cursor Episódio 03
Resumo Antigravity 2.0, Claude Code, Codex e Cursor configurados com governança de memória, prontos para trabalhar no seu repositório.

Cada agente lê instruções próprias na raiz do repositório. Os guias mostram como deixar Antigravity 2.0, Claude Code, Codex e Cursor seguindo as mesmas regras de memória e as mesmas skills.

Como usar

  1. Clone o repositório conn2flow-ai-workspace.
  2. Abra a pasta no agente de sua preferência.
  3. Peça ao agente para ler a pasta de memória antes de qualquer tarefa.

O resultado é o mesmo comportamento em qualquer ferramenta: o agente consulta a especificação, registra decisões e entrega em lotes pequenos.
